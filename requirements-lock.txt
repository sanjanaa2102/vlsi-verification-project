# Full, exact dependency closure for the UART + APB regression
# environment (what `python run_regression.py` and CI actually need),
# generated from a working venv and then reviewed/pruned by hand -- not
# a blind `pip freeze`.
#
# Deliberately narrower than requirements.txt: requirements.txt is this
# project's full direct-dependency list, including packages only used by
# phase2_llm (google-genai, for the LLM test-generation script) and
# pyuvm (a declared-but-currently-unused dependency, confirmed by
# grepping for `import pyuvm` across every active test/env file --
# reserved for a possible future phase, not removed from requirements.txt
# since that's outside Phase 6's scope). Neither phase2_llm nor pyuvm are
# exercised by the regression this lock file is for, so google-genai's
# entire transitive closure (google-auth, httpx, cryptography, pydantic,
# ~15 more) and pyuvm are intentionally excluded here.
#
# Regenerate by installing requirements.txt in a fresh venv, running the
# full regression successfully, then re-deriving this file the same way
# (pip freeze, then keep only what `pip show <direct dep>` traces back to
# for cocotb, cocotb-coverage, verible, yowasp-yosys, and z3-solver -- see
# the Phase 6/7 commit messages for the exact review that produced this.
#
# Phase 7 additions (formal verification): yowasp-yosys and
# yowasp-yosys-smtbmc (Yosys compiled to WebAssembly, pip-installable,
# no sudo/apt needed) and z3-solver (pip-installable Z3 with a working
# `z3` CLI binary) -- the SMT-based BMC/k-induction toolchain
# phase5_apb/formal/ uses via SymbiYosys (sby itself is not on PyPI;
# fetched separately at a pinned git tag by regression/formal.py into
# formal_tools/, not committed -- see that module's docstring).
